# Manual de Usuario Móvil — La Croassantina

Bienvenido al manual de la aplicación nativa de **La Croassantina** para Android. Esta app permite disfrutar de la experiencia del obrador artesanal directamente en la palma de tu mano, con una interfaz optimizada para pantallas táctiles.

![Banner La Croassantina](/img/home.png)

## ¿Qué ofrece la App Móvil?

La versión móvil incluye las funcionalidades clave para el cliente final:

- **Catálogo Táctil:** Navegación fluida por productos con carga bajo demanda (paginación).
- **Seguimiento de Pedidos:** Consulta el estado actual de tus compras desde el historial.
- **Gestión de Perfil:** Personaliza tu cuenta seleccionando una foto desde la galería de tu teléfono.
- **Carrito Reactivo:** Gestión de cantidades y promociones con cálculos instantáneos.

## Navegación Principal

La app utiliza una **Bottom Navigation Bar** (barra inferior) para un acceso rápido:

1. **Inicio:** Novedades y productos estrella.
2. **Catálogo:** Explorador completo por categorías.
3. **Promos:** Tus cupones disponibles.
4. **Pedidos:** Tu historial de compras.
5. **Carrito:** Tu cesta actual.
