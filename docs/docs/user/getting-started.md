# 🚀 Primeros Pasos

## Instalación

### Requisitos previos
- Android 8.0 o superior
- 100 MB de espacio disponible

### Pasos de instalación

1. **Descargar la app**
   - Visita [GitHub Releases](https://github.com/39Luka/Proyecto_intermodular_movil_kotlin/releases)
   - Descarga el APK más reciente

2. **Instalar**
   - Abre el APK descargado
   - Sigue las instrucciones en pantalla

3. **Primera ejecución**
   - Permite los permisos necesarios
   - Configura tu perfil

## Configuración inicial

```
1. Abre la aplicación
2. Acepta los términos y condiciones
3. Crea tu cuenta (si es necesario)
4. Autoriza permisos de:
   - Ubicación
   - Almacenamiento
   - Cámara (si aplicable)
5. ¡Listo! Ya puedes empezar
```
