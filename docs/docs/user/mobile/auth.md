# Registro e Inicio de Sesión

Para realizar pedidos en **La Croassantina** es necesario tener una sesión activa. El sistema está diseñado para que solo tengas que identificarte una vez.

## Iniciar Sesión

1. Introduce tu **email**.
2. Escribe tu **contraseña**.
3. Pulsa el botón **"Entrar"**.

![Login](/img/login.png)
*Formulario de inicio de sesión.*

## Crear una nueva cuenta

Si es tu primera vez en la aplicación:

1. Pulsa en el enlace **"Crea una cuenta"** en la parte inferior.
2. Rellena los campos:
   - **Email**: Asegúrate de que tenga un formato válido.
   - **Contraseña**: Debe tener al menos 8 caracteres para tu seguridad.
   - **Confirmar contraseña**: Repite la misma clave.
3. Pulsa **"Registrarse"**.

![Registro](/img/register.png)
*Pantalla de registro de nuevos usuarios.*

:::info Persistencia de Sesión
La aplicación recordará tus datos. Aunque cierres la app o reinicies tu teléfono, seguirás identificado hasta que decidas cerrar sesión manualmente desde tu perfil.
:::
