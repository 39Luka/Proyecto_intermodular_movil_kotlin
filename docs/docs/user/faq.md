# ❓ Preguntas Frecuentes (FAQ)

## Funcionamiento general

### ¿Cuánto cuesta la app?
La aplicación es **completamente gratuita**.

### ¿Necesito internet para usar la app?
Algunas funciones requieren internet (sincronización, actualizaciones).
Sin embargo, puedes usar muchas funciones en **modo offline**.

### ¿Cómo actualizar la app?
1. Abre **Google Play Store**
2. Busca "Proyecto Intermodular"
3. Toca **"Actualizar"**

Las actualizaciones se descargan automáticamente si lo tienes habilitado.

---

## Datos y privacidad

### ¿Es segura mi información?
✅ Sí. Usamos cifrado de grado militar (AES-256).

### ¿Comparten mis datos?
❌ No compartimos tus datos con terceros.
[Lee nuestra Política de Privacidad](https://github.com/39Luka/Proyecto_intermodular_movil_kotlin)

### ¿Puedo eliminar mi cuenta?
Sí. Ve a **Configuración → Cuenta → Eliminar cuenta**

---

## Compatibilidad

### ¿Funciona en iOS?
Actualmente solo disponible para Android.
iOS está en roadmap para futuras versiones.

### ¿Qué versión mínima de Android necesito?
Android 8.0 o superior.

### ¿Cuánto espacio ocupa?
Aproximadamente 100 MB (sin datos de usuario).
