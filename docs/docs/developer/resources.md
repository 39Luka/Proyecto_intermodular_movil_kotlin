# 📚 Recursos

Referencia rápida a herramientas y documentación oficial utilizada en La Croassantina.

---

## Kotlin & Android

### Documentación oficial
- [Kotlin Docs](https://kotlinlang.org/docs/) - Referencia del lenguaje.
- [Android Developers](https://developer.android.com/) - Portal principal.
- [Jetpack Compose](https://developer.android.com/jetpack/compose) - UI moderna.

### Librerías del proyecto
- [Retrofit](https://square.github.io/retrofit/) - Cliente HTTP.
- [Hilt (Dagger)](https://dagger.dev/hilt/) - Inyección de dependencias.
- [Coil](https://coil-kt.github.io/coil/compose/) - Carga de imágenes.
- [Jetpack DataStore](https://developer.android.com/topic/libraries/architecture/datastore) - Persistencia.

---

## Herramientas

### Desarrollo
- **Android Studio Ladybug** (o superior) - IDE principal.
- **Git** - Control de versiones.

### Testing
- **JUnit 4** - Runner de pruebas unitarias.
- **MockK** - Mocking nativo para Kotlin.
- **Turbine** - Testeo de flujos (Flow/StateFlow).
- **Compose UI Test** - Pruebas instrumentadas de interfaz.
